# Vilevi A1 Asset Prompts v1

Content ID: VILEVI-A1-V1
Purpose: scene-by-scene visual prompt package for creating the first asset set of the A1 Shorts concept.
Format: vertical 9:16
Style: realistic cinematic, everyday Vietnam, light suspense, light comedy, consistent environment and props.

## Global Consistency Prompt
Realistic cinematic Vietnamese street-side drink shop in daylight, authentic urban Vietnam atmosphere, small plastic tables and stools, natural Vietnamese customers, documentary-like lighting, realistic textures, vertical 9:16 composition, same red plastic chair as central prop, same orange street cat when present, no logos, no copyrighted characters, no celebrity likeness, believable everyday clothing.
